# Delivery contract and scope

Defaults distilled from a real iterative academic-PDF translation workflow:

- Chinese prose only; no English/Chinese side-by-side duplication.
- Keep original figures, tables, captions, numerical entries, axis labels, mathematical variables and formulas in their original language and formatting.
- Prefer original LaTeX → prose translation → translated LaTeX → compiled PDF. Preserve the author template where it remains readable with Chinese.
- Retain bibliography and author names; affiliations may remain in the original language as metadata. Translate abstract, sections, substantive footnotes, acknowledgments and author biographies when present.
- Exclude doctoral dissertations and PDFs longer than 50 pages unless current instructions say otherwise. “Exclude/remove from this batch” does not authorize destructive deletion of input files.
- Count the files that actually exist, not the number casually mentioned. Existing Chinese originals may be copied unchanged and identified as such.
- Batch delivery: individual PDFs together in a folder, not a ZIP. Output goes to the requested Downloads/delivery directory. Keep build intermediates separately.
- No automatic UI opening. Return links/paths and verified results.

A source PDF's original page count and a native translated LaTeX PDF's page count need not match because Chinese text reflows. Preserve completeness, figure/table/section numbering and readability; do not force identical pagination at the cost of tiny fonts. The overlay fallback normally preserves page count and page dimensions.

Do not publish copyrighted input papers, private project sources, full user conversations, personal paths, credentials or generated private artifacts in a public skill repository. Publishing a skill does not publish the translated paper.
